# Trainstation Vivalla: Skaparresan

Ett researchbaserat webbspel byggt för att presentera Trainstation Vivallas verksamhet på ett lekfullt och professionellt sätt.

## Spelidé

Spelaren styr ett litet Trainstation-tåg genom fem kreativa stationer:

1. Filmverkstan
2. Musikstudion
3. Gaming & E-sport
4. Kod & spel
5. Kreativ verkstad

Varje station bygger på offentlig information om Trainstation Vivalla som digital mötesplats för unga, med fokus på film, musik, gaming, programmering, digital design, robotik, handledning och gemenskap.

## Köra lokalt

```bash
npm install
npm run dev
```
